minerfan

A cryptocurrency miner for Linux and Android.

Switch it on and it mines. What it earns goes to a wallet that lives on your own device, and when you need the computer back it gets out of the way. There is no account to create and no pool of ours in the middle: the nodes it needs run inside the app itself.

Version 0.1.0. Free and open source under the BSD-3-Clause license.

What you can mine today

Two coins for now, and more on the way. Most of what a miner needs is shared between coins, so a new one is mostly a matter of adding its parameters. If there is one you would like to see, tell us.

CoinRuns onHow it mines
Monero XMR CPU Through your own P2Pool node. Every Monero block that P2Pool finds pays the miners with recent shares directly, so there is nothing to withdraw.
Cryptoescudo CESC GPU (OpenCL) Solo, on the app's own light node. You choose how much of the network to take; the default is a quarter.

Coins that use different hardware can run side by side, one on the processor and another on the graphics card.

How it behaves

It shares the machine. In the default balanced profile the miner gives up a thread for every core your other programs are using, pauses when they need all of it, and hands back the memory it borrowed when memory runs low. If you would rather it did not hold back, pick Performance; on a laptop or a phone, Eco.

It keeps your keys. Each coin gets a wallet the first time you start the app, and the miners pay into it. You can receive, send and write down the recovery words. The keys stay on the device, encrypted.

It knows people. A contact is a public key with a short callsign you can read out loud, plus whatever you want to keep about them. You can hand over your own details as a QR code; it is signed, so nobody can swap the addresses on the way.

It has a room for each coin. People mining the same coin can talk in a chat that runs over the app's own I2P node. There is no server hosting it and nobody moderating it. Everyone in the room keeps the last two weeks, which is also what a newcomer gets to read, and anything you do not want to see you can mute.

It is one program. All of the above, the I2P node included, is written in Dart and Flutter and ships inside the app. It does not download or start miners or daemons written by someone else.

Download

Android

Android 7.0 or newer. On phones the CPU coins run on the processor; GPU coins need a phone whose maker lets apps use OpenCL.

minerfan-android.apk

Open the file on the phone and allow the install when Android asks. It is not on Google Play, whose rules do not allow apps that mine on the device.

Linux

64-bit PC with GTK 3, which any common desktop has. GPU mining uses the OpenCL driver of your graphics card.

minerfan-linux-x64.tar.gz 
tar xzf minerfan-linux-x64.tar.gz
mv minerfan ~/.local/opt/
~/.local/opt/minerfan/minerfan

The first start adds a launcher and a dock icon.

Checksums and older versions are on the releases page. For Windows and macOS, build it from the source.

Suggest a coin

We add coins as we go, and requests help us decide which one comes next. To ask for one, open a request on GitHub:

  1. Sign in to GitHub (a free account is enough).
  2. Open the coin request form.
  3. Fill in the coin's name, ticker and mining algorithm, and links to its website and source code. A block explorer and the size of its network help too.
  4. Say why you would like to mine it, and on what hardware.

Before you do, have a look at the requests already open; if yours is there, a thumbs-up on it counts as a vote. Coins whose node and mining rules we can write in Dart, under a permissive license, are the easiest to add.

Questions

Will it wear out my laptop or phone?

Mining does use a lot of power, which is why it only starts when you switch it on. Thermal control slows it down when the device gets hot, and the Eco profile uses half the threads.

What does the chat show about me?

Messages are public. Anyone in the room can read them, with your callsign next to them, and members keep them for two weeks. Mining itself only talks to the networks of the coins you mine.

Is it open source?

Yes, under the BSD-3-Clause license. The parts ported from other projects keep their own permissive licenses, listed in the repository.
